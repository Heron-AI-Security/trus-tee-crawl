# Archived kits

These are the kits of the earlier milestones (m481 to m522), the shared cluster kit (`tcshared`), the resume script (`cln-resume`) and one hand-over block (`p4g-tools-test`). They are kept for the record, exactly as they ran: nothing inside them was edited when they were moved here.

They are not meant to be run from here. The five `m5xx-build` scripts call `m481-build` by its old path (`ops/kits/m481-build/...`), which no longer exists; a rerun would need that path changed. The kit to run now is `ops/kits/run-kit`.
